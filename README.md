<h1>Пропиши в консоль:</h1>

* python -m venv .venv
> Ты создаешь виртуальную среду

* .venv\Scripts\activate
> Заходишь в нее

* pip install -r requirements.txt ( **ГЛАВНОЕ ДЕЛАТЬ В ВИРТУАЛЬНОЙ СРЕДЕ, пункт 2** )
> Установишь все зависимости

* python main.py ( **ГЛАВНОЕ ДЕЛАТЬ В ВИРТУАЛЬНОЙ СРЕДЕ, пункт 2** )
> Запускаешь бота
